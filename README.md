# Description

A final project for *TripleTen's* software engineering course. This project is a *responsive* _front-end_ application using the *React* library with *Vite* scaffolding.

# Project Details

This project is designed to be a mock representation of an interactive website to be used by guests who are visiting or planning to visit the hit new attraction Jurassic Park©. The site offers an interactive map that guests can use to access detailed information on the parks various attractions and the current weather, as well as a virtual tour going over the finer points of the park including safety and accommodations for those still _on the fence_ about buying tickets.

# Technical Details

The *main* page (_accessible via clicking the jurassic park logo_) consists of a map that has buttons placed on it using absolute positioning. Each button, when clicked, populates a popup modal with the title, description, and image found in the constants file. The *park-tour* page (_accessible via clicking the "Take a tour" text_) consists of a component filled with text and image elements describing the amenities available to the theoretical Park-Guest. A weather card coordinating to the approximate location of the park (_specifically San José, Costa Rica_) displays the current weather and temperature of the park (_again, just to be specific, the actual coordinates for the park are empty atlantic ocean, San José, CR is close enough I think_).
